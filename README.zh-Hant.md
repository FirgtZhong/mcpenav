# McPenav 網頁檔案

[简体中文](README.md) · [English](README.en.md) · [Русский](README.ru.md)

McPenav（Minecraft PE Navigation）是最早為 Minecraft（我的世界）0.14 玩家整理的綜合性網頁導覽站，提供伺服器入口、原版與模組客戶端下載，以及一些實用工具。

線上體驗：https://mcpenav.top/

本倉庫為主站原始碼，由 Cloudflare Pages 託管，更新較慢。

## 核心功能

- 資源導覽：分類整理 Minecraft 伺服器入口、客戶端下載與實用工具。
- 快速存取：全站靜態部署，載入快，無廣告。
- 響應式設計：PC、平板、手機瀏覽器都能用。
- 個人化設定：自訂背景、主題色與導覽卡片。

## 衍生專案

伺服器收錄已獨立到子網域維護：

**MCPEMAP · 伺服器收錄站**
https://mc.mcpenav.top/

同一個網域，前綴 收錄 Minecraft 攜帶版 0.13～1.1 各系列伺服器，人工審核、免費收錄，支援按版本、類型、標籤篩選。

伺服器列表、人氣排行、統計與線上資料以該站為準；本倉庫的主站頁面僅作為入口與歷史留存。
