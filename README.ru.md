# Исходники сайта McPenav

[简体中文](README.md) · [English](README.en.md) · [繁體中文](README.zh-Hant.md)

McPenav (Minecraft PE Navigation) — первый навигационный сайт проекта для игроков Minecraft 0.14: ссылки на серверы, оригинальный и модифицированные клиенты, а также полезные инструменты.

Сайт: https://mcpenav.top/

В этом репозитории лежат исходники основного сайта. Он размещён на Cloudflare Pages и обновляется реже, чем дочерние проекты.

## Возможности

- Навигация по ресурсам: ссылки на серверы Minecraft, клиенты и инструменты, разложенные по разделам.
- Быстрый доступ: полностью статический сайт, без рекламы.
- Адаптивная вёрстка: ПК, планшеты и телефоны.
- Настройка под себя: фон, цвет темы и карточки навигации.

## Дочерний проект

Каталог серверов теперь ведётся отдельно, на поддомене:

**MCPEMAP · каталог серверов**
https://mc.mcpenav.top/

Тот же домен, префикс. Собираем серверы Minecraft Pocket Edition версий 0.13–1.1: добавление бесплатное, все заявки проверяются вручную, есть фильтры по версии, типу и тегам.

Список серверов, рейтинг, статистика и данные об онлайне — на том сайте. Здесь остаются только входная страница и архив исходников.
