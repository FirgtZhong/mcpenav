# McPenav Web Files

[简体中文](README.md) · [Русский](README.ru.md) · [繁體中文](README.zh-Hant.md)

McPenav (Minecraft PE Navigation) is the original navigation site built for Minecraft 0.14 players: server links, original and modded client downloads, and a few useful tools.

Live site: https://mcpenav.top/

This repository holds the source of the main site, hosted on Cloudflare Pages. It receives updates less often than the projects below.

## Features

- Resource navigation: Minecraft server links, client downloads and tools, sorted into sections.
- Fast access: fully static, quick to load, no ads.
- Responsive layout: works on PC, tablets and phones.
- Personalisation: custom background, theme colour and navigation cards.

## Derivative project

The server directory now lives on a subdomain:

**MCPEMAP · Server Directory**
https://mc.mcpenav.top/

Same domain, prefix. It lists Minecraft Pocket Edition 0.13–1.1 servers, free to submit and reviewed by hand, with filters by version, type and tag.

Server lists, rankings, stats and online data come from that site. The pages here are only an entry point and a historical archive.
